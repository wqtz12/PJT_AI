# Project: Team Cost & Profit Closing System Business Process

## Business Process

## 1.원본 데이터 다운로드

- 요약손익계산서와 월별 손익계산서 Site에 접속한다. (SSO 로그인 필요)
- 조회 버튼을 Click하여 Grid에 데이터가 조회되게 한다.
- 엑셀다운로드 버튼을 Click하여 Excel을 다운로드한다.
- 다운로드 폴더에 저장된 매출/영업이익 원천 데이터를 Project 폴더 내의 `원천데이터` 폴더 경로로 복사한다.
- 원본 데이터 다운로드가 불가할 경우 로그 처리 후 데이터 추출 프로세스를 실행한다. 

## 2.데이터 추출

- 금주(오늘 날짜의 주차)의 폴더 경로에 있는 데이터(Excel) 파일의 데이터를 pandas를 사용하여 추출한다.
- 요약손익계산서와 월별 손익계산서를 서로 다른 Group으로 데이터를 추출한다.
- 주 마감일 경우 전주 데이터를 추출하고 월 마감일 경우 전월 데이터를 추출한다. (주/월의 구분은 사용에게 질의한다.)

## 3.데이터 가공

- **구분자 값 추가:** 금주에 추출한 요약손익계산서 데이터 Row별로 '몇 월 몇 주차'의 구분자 값을 추가한다. (예: `2026_1주차`)
- **요약손익계산서 정보 추가:**금주에 추출한 요약손익계산서 데이터 Row별로 '고객사','WBS유형','프로젝트 담당자', '이익률', 'Sold', '계약체결'
- **월별손익계산서 정보 추가:**금주에 추출한 월별손익계산서 데이터 Row별로 '1분기매출','1분기정산전영업이익','2분기매출','2분기정산전영업이익','3분기매출','3분기정산전영업이익','4분기매출','4분기정산전영업이익' (분기별 매출, 정산전 영업이익 합계 정보를 넣는다)
- **데이터 관리:** 공통코드 정보를 관리한다.
  - 고객사 코드 매핑 : 고객사는 LG에너지솔루션, LG화학, LG생활건강, 기타 (앞의 3가지 아니면 모두 기타로 분류한다.)
  - WBS유형 코드 매핑 : 요약손익계산서의 사업유형이 SI면 SI, SM면 SM으로 매핑한다.
  - 프로젝트 담당자 매핑 : 요약손익계산서의 PM 열의 값과 사용자 정의 값을 입력하여 관리한다. (ex. PM - 전병순 | 담당자 - 전병순 )
  - Sold 코드 매핑 : 요약손익계산서의 UD구분이 Y면 UD, 사업유형이 SI면 SI, SM이면 SM으로 매핑한다.
  - 프로젝트 코드 매핑 : 요약손익계산서의 Object코드, Object상세코드를  그룹핑하여 매핑한다. 

- **데이터 정제:** 추출된 정보와 공통코드 정보를 사용하여 합계 데이터를 정제한다.
  - **금주 합계:** 요약손익계산서와 월별손익계산서를 사용하여 연간 매출/영업이익 합계, 분기별 매출/영업이익 합계, 월별 매출/영업이익 합계를 계산한다.
  - **항목별 합계:** 고객사, WBS유형, 프로젝트 담당자, Sold 기준으로 합계 데이터를 계산한다.
  - **공통코드 합계:** 공통코드별로 합계 데이터를 계산한다.
  - **프로젝트 코드 합계:** 프로젝트 코드별로 합계 데이터를 계산한다.
  - **전주 대비 증감:** 전주 데이터 대비 합계 차이를 계산한다.
  - **버전 대비 증감:** 금주 데이터 중 이전 버전 대비 합계 차이를 계산한다.
  
- **데이터 저장 (Excel 표):**
  - **주간데이터:** 금주와 전주 데이터의 정제된 내용을 비교하여 Excel 표 형식으로 저장한다.
  - **월간데이터:** 당월과 전월 데이터의 정제된 내용을 비교하여 Excel 표 형식으로 저장한다. 
  - **작업데이터:** 원본 데이터 추가를 고려해 현재 버전과 이전 버전에 정제된 내용을 비교하여 Excel 표 형식으로 저장한다.
  - **관리 정책:** 위 3가지 데이터는 모두 별개의 Excel 파일로 관리한다.
